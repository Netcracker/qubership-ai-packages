В Go-пакете `set` комментарии к экспортируемым объявлениям пишут по-русски. Напишите doc-комментарий к методу:

```go
// Set — множество строк. Нулевое значение готово к работе.
type Set struct {
	m map[string]struct{}
}

func (s *Set) Len() int {
	return len(s.m)
}
```

Дайте только комментарий вместе с сигнатурой метода.

окружения `FOO_CONFIG`. Сейчас пользователь запустил `foo sync`, и открыть файл не удалось: у пользователя нет прав
на чтение `/etc/foo/config.yaml` (`EACCES`). Утилита печатает сообщение в stderr и завершается с кодом 2; без
конфигурации она ничего не делает.

Интерфейс утилиты локализован на русский. Напишите сообщение, которое она печатает в stderr. Дайте только текст

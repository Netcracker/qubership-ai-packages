В веб-приложении для команд есть вкладка «Упоминания». В ней собираются комментарии, где коллеги упомянули
пользователя через `@имя`. Пользователь не может сам добавить запись в этот список: записи появляются, только когда
его упоминает кто-то другой. Кнопок на пустой вкладке нет.

Напишите текст пустого состояния этой вкладки, который видит пользователь, когда его ещё никто не упоминал. Дайте
только текст.

В репозитории описания pull request пишут по-русски. Pull request меняет одну строку в `go.mod`:

```diff
-	github.com/stretchr/testify v1.9.0
+	github.com/stretchr/testify v1.10.0
```

и соответствующие строки в `go.sum`. Код не меняется, тесты проходят как раньше. Обновление нужно, чтобы держать
зависимости свежими; ничего конкретного из новой версии проекту не нужно.

Напишите описание pull request (без заголовка). Дайте только текст описания.

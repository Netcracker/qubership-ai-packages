The maxResultBuffer connection property limits how much client memory the rows of one result can take. Select fewer rows or columns, or turn autocommit off and call Statement.setFetchSize, so that the driver reads the rows in batches and counts each batch separately. If results this large are expected, raise maxResultBuffer in the JDBC URL or the DataSource to more than {1,number,#} bytes. It accepts a byte count, a size with a decimal K, M, G, or T suffix (1M is 1000000 bytes), or a percent of the maximum heap with a p suffix. The driver caps it at 90% of the maximum heap, so a larger limit also needs a larger -Xmx.

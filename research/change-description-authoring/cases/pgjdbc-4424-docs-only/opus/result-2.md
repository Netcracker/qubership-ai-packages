TESTING.md told contributors to add a new test class to "the test suite" and said most tests were JUnit 4. The pull request template also asked whether new test classes had been added "to an existing test suite in alphabetical order". No suite class exists to register a test in. Every test under `pgjdbc/src/test` is JUnit 5, and Gradle finds test classes without one. On `master`, `git grep -lE 'org\.junit\.(Test|Assert|runner)' -- pgjdbc/src/test` prints nothing. A JUnit 4 test in `pgjdbc` would not compile anyway, because [`pgjdbc/build.gradle.kts`](https://github.com/pgjdbc/pgjdbc/blob/f171cd8af6fc5f341c765309af0c1ab0db6fbfb7/pgjdbc/build.gradle.kts#L157-L162) rejects `junit:junit` on the test compile classpath.

[TESTING.md §5 Extending the test suite with new tests](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/TESTING.md#5---extending-the-test-suite-with-new-tests) now says to write new tests with JUnit 5 under `pgjdbc/src/test`. It also names the two modules that keep JUnit 4 tests because they need a JUnit 4 runner: `pgjdbc-junit4-test` uses classloader-leak-test and `pgjdbc-osgi-test` uses Pax Exam. Searched across the whole repository, the same `git grep` finds JUnit 4 files only in those two modules. In [§6 Guidelines for developing new tests](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/TESTING.md#6---guidelines-for-developing-new-tests), the JUnit 4 `Assert` examples are replaced with JUnit 5 `Assertions`.

The template asked about tests in both "[New Feature Submissions](https://github.com/pgjdbc/pgjdbc/blob/f171cd8af6fc5f341c765309af0c1ab0db6fbfb7/.github/pull_request_template.md#new-feature-submissions)" and "Changes to Existing Features". Those test questions now appear once, in a single "[Tests and style](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/.github/pull_request_template.md#tests-and-style)" section. That section adds one new question: for a bug fix, does the new test fail without the fix? The item that asks for an explanation of the changes moves to "All Submissions" because it applies to every pull request.

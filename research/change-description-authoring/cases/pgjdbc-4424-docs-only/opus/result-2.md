TESTING.md said most tests were JUnit 4 and told contributors to add a new test class to the test suite. The pull request template also asked whether new test classes were added to an existing test suite in alphabetical order. Neither instruction applies any more. Tests under `pgjdbc/src/test` are all JUnit 5, and Gradle discovers them without a suite class. `git grep -lE 'org\.junit\.(Test|Assert|runner)' -- pgjdbc/src/test` on `master` prints nothing. [`pgjdbc/build.gradle.kts`](https://github.com/pgjdbc/pgjdbc/blob/f171cd8af6fc5f341c765309af0c1ab0db6fbfb7/pgjdbc/build.gradle.kts#L157-L162) rejects `junit:junit` on the test compile classpath, so a JUnit 4 test under `pgjdbc` does not compile.

[TESTING.md §5 Extending the test suite with new tests](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/TESTING.md#5---extending-the-test-suite-with-new-tests) now says that new tests use JUnit 5 and go under `pgjdbc/src/test`. It also names the two modules that keep JUnit 4 tests because they need a JUnit 4 runner: `pgjdbc-junit4-test` for classloader-leak-test, and `pgjdbc-osgi-test` for Pax Exam. Running the same `git grep` over the whole repository finds files only in those two modules. The examples in [§6 Guidelines for developing new tests](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/TESTING.md#6---guidelines-for-developing-new-tests) now use JUnit 5 `Assertions` instead of JUnit 4 `Assert`.

The template asked about tests in both "New Feature Submissions" and "Changes to Existing Features". A single [Tests and style](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/.github/pull_request_template.md#tests-and-style) section now asks four things: whether the changes are covered by tests, whether a bug fix's new test fails without the fix, whether the tests pass locally, and whether `./gradlew styleCheck` passes. The item that asks for an explanation of the changes moves to [All Submissions](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/.github/pull_request_template.md#all-submissions) because it applies to every pull request.

[TESTING.md §5 Extending the test suite with new tests](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/TESTING.md#5---extending-the-test-suite-with-new-tests) said most tests were JUnit 4 and told contributors to add a new test class to the test suite. The pull request template asked whether new test classes had been added to an existing test suite in alphabetical order. The tests under `pgjdbc/src/test` are all JUnit 5 now, and Gradle discovers them without a suite class. Both instructions sent contributors looking for a suite that does not exist.

Section 5 now tells contributors to write new tests with JUnit 5 under `pgjdbc/src/test`. It names the two modules that keep JUnit 4 tests because they need a JUnit 4 runner: `pgjdbc-junit4-test` (classloader-leak-test) and `pgjdbc-osgi-test` (Pax Exam). In [§6 Guidelines for developing new tests](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/TESTING.md#6---guidelines-for-developing-new-tests), the JUnit 4 `Assert` examples become JUnit 5 `Assertions`. In the template, the test questions were split between [New Feature Submissions](https://github.com/pgjdbc/pgjdbc/blob/f171cd8af6fc5f341c765309af0c1ab0db6fbfb7/.github/pull_request_template.md#new-feature-submissions) and "Changes to Existing Features". They are now one [Tests and style](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/.github/pull_request_template.md#tests-and-style) section. That section adds a new question: for a bug fix, does the new test fail without the fix? The question that asks for an explanation of the change moves to [All Submissions](https://github.com/pgjdbc/pgjdbc/blob/e6bf0181251063d4cb2fc8324e28fc4f6cde1313/.github/pull_request_template.md#all-submissions), because it applies to every pull request.

This changes documentation only, and no test was added or run. I checked the claims about the code in two ways:

- On `master`, `git grep -lE 'org\.junit\.(Test|Assert|runner)' -- pgjdbc/src/test` prints nothing. The same search over the whole repository finds files only under `pgjdbc-junit4-test` and `pgjdbc-osgi-test`.
- [`pgjdbc/build.gradle.kts` lines 157–162](https://github.com/pgjdbc/pgjdbc/blob/f171cd8af6fc5f341c765309af0c1ab0db6fbfb7/pgjdbc/build.gradle.kts#L157-L162) reject `junit:junit` on the test compile classpath, so a JUnit 4 test under `pgjdbc` does not compile.

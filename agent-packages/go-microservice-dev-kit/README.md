# go-microservice-dev-kit

Umbrella APM package for Go microservices. Pulls in instructions and
skills for every Qubership platform library a service needs via
transitive APM dependencies. Install one package and the agent picks
up the full stack automatically.

It also pulls in [`godoc-authoring`](../godoc-authoring/), which says
what a Go doc comment carries and in which order, so comments read the
same way across services.

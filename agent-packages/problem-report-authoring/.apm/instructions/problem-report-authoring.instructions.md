description: "Trigger for the problem-report-authoring skill: load it before writing or reviewing a bug report, a feature or change request, or a short problem message to a colleague."
applyTo: "**"
---

Before writing or reviewing a report of a problem someone else has to act on, load `problem-report-authoring`, and with
it the developer-style skill of the language the report is written in (`english-developer-style` for English). That
covers a bug report or issue in any tracker or on a mailing list, in someone else's project or your own, a feature or
change request, and a short problem message to a colleague. A session that reproduced something reaches this point when
it is asked to write it up, file it, or tell the team. Also load it for "review this draft", "is this ready to file",
and before `gh issue create`, `glab issue create`, or a Jira create screen.
